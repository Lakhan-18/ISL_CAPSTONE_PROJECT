# Conversational Indian Sign Language (ISL) Recognition

This project explores Indian Sign Language (ISL) recognition using computer vision and deep learning, converting recognized gestures into text and speech as a step toward accessible, conversational communication.

### Source Code

The complete source code, dataset, metadata, trained models, scripts, and results are available in the ZIP file attached to this repository.

**To access the project files:**
1. Open the repository on GitHub.
2. Download the provided `.zip` file.
3. Extract the ZIP file to access the complete project directory and its contents.

### Technologies
Python, TensorFlow/Keras, MediaPipe, OpenCV, and NumPy.
